抽屉里有什么

每张卡管一件事。插件读的是本机已有的文件，不替你保管任何密钥。

账号库

登录过的账号，自动归档

从 auth 目录的 .info 快照和 secret-storage.xml 里读出来。官方入口登录或切号后 1.5 秒，新凭据就进了库。支持筛选、五种排序、重命名与 JSON 导入导出。

codebuddy-accounts/snapshots/<uid>@<domain>.info
额度

快过期的，先用掉

每个账号一张额度卡，套餐分组、细项到期、今日消耗都在里面。状态栏有五种读数维度；低额度提醒、自动刷新与智能调度按你设的阈值跑。

刷新间隔 15 min · 阈值 20% · 冷却 10 min
历史

对话不跟着账号走

跨账号搜会话、按项目看日报周报，也能把别的账号的历史合并进当前账号——只新增，不覆盖、不删除。支持复制、导出 Markdown 与打开会话目录。

history/<workspace>/index.json → index.json.bak
今日签到对账号库所有账号执行每日签到，逐账号显示已签到与获得积分。接口非官方，可在设置页改路径或整体关闭。
成长中心逐账号展示任务完成数、待领奖与进行中进度；「一键完成」= 接取 + 上报客户端行为事件 + 领奖，另附独立窗口与旅行巡检、保活、补签。
模型限额同时监控多个模型，每条规则独立限额（如 deepseek 200、gpt-5 100），达标提醒切号，剩余低于阈值时预警。
消耗明细按账号与时间范围拉取每次请求的时间、产品、模型、积分、使用端与提示词摘要，含合计积分与模型分布，支持分页。

切号是一次可以反悔的写入

写回 IDE 的 secret-storage.xml 之前先留一份备份；切换不生效、IDE 退出时用旧值覆盖、热切换校验失败，三种情况都有兜底。

  1. 选中卡片，点「切换」会询问是否同步历史会话索引，当前激活账号不可删除。
  2. 写入凭据把选定账号的快照写回 secret-storage.xml。
  3. 同目录留一份备份secret-storage.xml.bak-<时间戳>，回滚就是从这里取。
  4. 重启 IDE 生效CodeBuddy 插件启动时才重新读取凭据。热切换是实验特性，校验失败会安全降级并提示重启。
  5. 想反悔，点「回滚」恢复上一次切换前的凭据；也能一键强制登出当前账号。

看板上的读数

今日消耗积分加大号数字，数值变化时从旧值滚动到新值，瞬间的增量以香槟金高亮，位数变化不挤动布局。
30 天到期看板按套餐类型合并，显示同类型在多个账号上的账号数、细项数与剩余合计。
状态栏额度五种维度可选；数值下降时平滑递减，上升时直接显示新值。

历史是所有账号共用的

扫描各账号 history/<工作区>/index.json，按今天 / 昨天 / 最近 7 天 / 更早分组，消息按 createdAt 排序，文本与工具调用分块渲染，工具结果只显示摘要。

日报 / 周报默认按项目统计，项目名由会话消息里的绝对路径反推，解析不到时回退为 项目 <hash 前 8 位>；另有账号 / 日期 / 时段 / 会话类型维度。
左侧筛选维度分布条与「今天 / 昨天 / 本周」快捷按钮都可点选，筛选结果同时作用于复制 Markdown 与生成提示词。
用 CodeBuddy 生成把统计事实拼成提示词复制到剪贴板并打开对话窗口，粘贴发送后由模型生成正文。
历史共享把全部账号的会话索引合并进当前激活账号，复制目标账号缺失的消息目录；也可批量同步全部账号。

同步时遵守的三条

01只处理目标账号已存在的工作区目录
02只新增，不覆盖、不删除
03单个会话消息复制上限 2000 个文件
备份覆盖历史索引前生成 index.json.bak
主键uid@domain（同 UID 不同域名算两个账号）

同步后重启 IDE，让 CodeBuddy 侧边栏刷新。

三步开始用

  1. 打开面板Tools | CodeBuddy Account Manager，或者点状态栏上的读数。
  2. 把账号收进库点「从 auth 目录导入」，本机已有的账号就变成一张张卡片。
  3. 选中，切换写入前自动备份，按提示重启 IDE 生效；想反悔就点「回滚」。

已知限制

常规切号要重启CodeBuddy 插件启动时才读取凭据并缓存。
热切换会降级依赖插件内部类，CodeBuddy 版本变更时自动退回重启生效。
平台范围仅 Windows 与 IntelliJ IDEA 2026.2（build 262）。
搜索索引设置页与动作未参与 IDE 全局搜索索引。
逆向接口签到与成长中心接口非官方公开，字段可能随版本变化，失败只提示不影响账号。

凭据只留在这台机器。

插件直接读写本机已有的 CodeBuddy 凭据文件与历史目录，不上传、不代理任何账号数据。额度查询只在本机与 CodeBuddy 服务端之间进行；成长中心与签到请求也只与官方服务端通信。导出的 JSON 与 Markdown 包含完整凭据，由你自己保管。

写入 secret-storage.xml 前生成带时间戳的 .bak 备份，覆盖历史索引前生成 index.json.bak。所有降级路径都只提示，不改写别的账号。

本插件是独立的本地工具，不是 CodeBuddy 官方组件。使用前请确认符合你所使用服务的使用条款。
