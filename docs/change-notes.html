0.45.1 — 当前版本

  • 账号面板操作逻辑重做：工具栏动作只认勾选，无勾选时提示先勾选；动作执行期间禁用工具栏，避免重复提交。切换前默认弹确认框（⋯ 菜单可关），新增卡片右键菜单与双击切号，卡片显示「待重启生效」。
  • 操作记录落盘：切号 / 删除 / 刷新 / 导入导出与失败原因写入 codebuddy-accounts/operations.log，⋯ →「操作记录…」直接打开，不用再翻 idea.log。
  • 额度刷新更可靠：批量刷新改并发提交并汇总失败明细，接口网络抖动自动重试一次，401 / 403 给可操作提示；刷新失败保留上一次读数并标记过期，不再整片清空。
  • 凭据与账号库更安全：快照改原子写，凭据备份只保留最近 10 份；删除账号改为移入 trash 可找回；导入前给出「新增 / 覆盖」预览，导出明文凭据前二次确认。
  • 状态栏按 workspace 对齐：显示当前项目的当前对话标题，其余项目按「等确认 > 思考中 > 输出速度」排序；工具执行期间持续刷新活动时间，长工具不再中途掉「空闲」。
  • 桌宠确认策略三档可配：一直等人工 / 超时没人管就放行 / 自动放行，页面与 hook 通道共用；凭证、扣费、对外分发类调用始终人工；扣费卡只提示不代点，并新增逐次代点审计。
  • 桌宠台词新增配套动作与「代码规范 / 注意事项」池；统一业务日出口，可用 -Dcodebuddy.account.dayZone 覆盖时区。
  • 修复历史归档丢失模型信息、后台确认卡积压、切号失败仍补写待生效记录、额度读数显示「12,30」等问题；账号面板组件拆分，用量统计与成长计划配色统一。

0.10.3 — 首个公开版本

  • 账号库：从 auth 目录与 IDE 凭据导入账号快照，官方入口登录/切号后自动归档。
  • 卡片式账号列表：别名、当前激活徽标、企业/个人标签、Token 状态、额度进度条；支持筛选与五种排序。
  • 一键切号、回滚上一次切换、强制登出，写入前自动备份 secret-storage.xml，并支持待生效切换补偿。
  • 额度监控：自动刷新、低额度提醒、额度明细窗口（套餐分组折叠、细项到期时间、多账号汇总）。
  • 智能调度：优先消耗快过期额度，其次选择剩余最多的账号；支持阈值自动切换。
  • 状态栏组件：当前账号与额度，五种额度维度，悬停明细，点击打开面板。
  • 历史对话：跨账号浏览与搜索、账号过滤、复制、导出 Markdown、打开会话目录；支持历史共享与批量同步。
  • 设置页：刷新间隔、提醒阈值、历史同步策略、热切换（实验）、自动调度、状态栏维度、启动时 token 检查。
  • 限制：仅 Windows 与 IDEA 2026.2（build 262）；常规切号需重启 IDE。
