0.22.3 — 当前版本

  • 界面改版「档案柜」：账号卡片、看板、工具栏与状态栏统一为冷蓝灰档案纸 + 墨蓝 + 朱印 + 黄铜读数；面板固定为浅色，不随 IDE 深色主题变暗。
  • 成长中心任务：逐账号展示任务完成数、待领奖与进行中进度；「一键完成」自动接取任务、上报客户端行为事件并领取达标奖励。
  • 成长中心独立窗口：可切换账号，提供旅行巡检、活跃上报、全部保活、连登兑换、抽奖、补签昨日与刷新；双击任务行可单独执行。
  • 模型积分限额：可同时监控多个模型，每条规则独立限额与预警阈值；模型从官方目录加载或手填关键字，达标时提醒切换账号。
  • 消耗明细支持翻页拉取完整周期数据；设置页新增成长中心与模型限额配置，行为上报类任务可单独关闭。
  • 今日消耗积分卡片重排为大号数字 + 单位 + 次级指标，数值变化时滚动并高亮增量；状态栏额度改为平滑递减动画，位数变化不挤动布局。

成长中心与签到接口来自对官方前端包与客户端行为上报协议的整理，非官方公开接口，路径与字段可能随版本变化；失败只提示，可在设置页改路径或关闭。限额监控只做统计与预警，不会拦截客户端的模型调用。

0.11.3

  • 对话日报 / 周报按项目统计：新增「按项目」维度与明细表项目列，项目名由会话消息里的路径反推，解析不到时显示为「项目 + hash 前 8 位」。
  • 新增「用 CodeBuddy 生成」：把统计事实拼成提示词复制到剪贴板并打开 CodeBuddy 对话窗口，粘贴发送后由模型生成日报 / 周报正文。
  • 周报区间改为本周一 ~ 今天，按钮与标题统一为「本周周报」。
  • 首页「今日消耗积分」改为加大号数字卡片，并在同一张卡片右侧显示「剩余积分」。
  • 新增今日签到卡片与「一键签到」：对所有账号执行每日签到并展示各账号状态（实验特性，接口非官方，可在设置页改路径或关闭）。
  • 日报 / 周报窗口左侧可筛选：维度分布条目点击即筛选右侧明细，并新增「今天 / 昨天 / 本周」时间快捷筛选。
  • 日报 / 周报窗口新增会话搜索框（会话名 / 项目 / 账号 / 类型）。
  • 首页新增「智能调度」卡片：开关状态、热切换可用性、阈值、上次调度时间与冷却状态，一键跳转设置。

0.11.2

  • 首页看板：账号总数、额度总剩余、7 天内到期、低额度账号四个指标，加账号额度排行、30 天到期看板与数据状态，可与卡片视图一键切换。
  • 首页新增卡片：今日消耗积分、今日对话、今日消耗明细（合计 + 模型分布 + 最近 6 次请求），后台按天缓存拉取。
  • 首页所有卡片可点击跳转对应功能页；到期看板改为按套餐类型合并，展示账号数、细项数与剩余合计。
  • 消耗明细窗口：按账号与时间范围查看每次请求的时间、产品、模型、积分、使用端与提示词摘要，含合计与模型分布。
  • 对话日报 / 周报：基于本地历史对话生成今日日报与近 7 天周报，支持按账号、日期、时段、会话类型四个维度统计，可复制 Markdown。
  • 修复消耗明细一直停留在「正在读取」：补充请求超时与异常兜底，回调统一切回 EDT。

0.10.3 — 首个公开版本

  • 账号库：从 auth 目录与 IDE 凭据导入账号快照，官方入口登录/切号后自动归档。
  • 卡片式账号列表：别名、当前激活徽标、企业/个人标签、Token 状态、额度进度条；支持筛选与五种排序。
  • 一键切号、回滚上一次切换、强制登出，写入前自动备份 secret-storage.xml，并支持待生效切换补偿。
  • 额度监控：自动刷新、低额度提醒、额度明细窗口（套餐分组折叠、细项到期时间、多账号汇总）。
  • 智能调度：优先消耗快过期额度，其次选择剩余最多的账号；支持阈值自动切换。
  • 状态栏组件：当前账号与额度，五种额度维度，悬停明细，点击打开面板。
  • 历史对话：跨账号浏览与搜索、账号过滤、复制、导出 Markdown、打开会话目录；支持历史共享与批量同步。
  • 设置页：刷新间隔、提醒阈值、历史同步策略、热切换（实验）、自动调度、状态栏维度、启动时 token 检查。
  • 限制：仅 Windows 与 IDEA 2026.2（build 262）；常规切号需重启 IDE。
