CodeBuddy Account Manager is a JetBrains IDE plugin for managing multiple CodeBuddy (coding-copilot-jetbrains) accounts: import credential snapshots, switch accounts in one click, monitor quota with detailed breakdowns, and browse or merge conversation history across accounts.

在 JetBrains IDE 中统一管理多个 CodeBuddy（coding-copilot-jetbrains） 账号：批量导入凭据、一键切号与回滚、额度监控与明细、跨账号历史对话浏览与合并，并把当前账号与剩余额度常驻在状态栏。

插件直接读写本机已有的 CodeBuddy 凭据文件与历史目录，不把任何账号数据上传到第三方服务器。

核心功能

  • 账号库导入：自动识别 CodeBuddy auth 目录下的 .info 凭据快照，并读取当前 IDE 已登录的凭据；官方入口登录/切号后自动归档。
  • 卡片式账号列表：头像、别名、当前激活徽标、企业/个人标签、手机号、认证域、Token 状态、额度进度条。
  • 筛选与排序：按名称 / UID / 域名 / 手机号筛选；支持默认、按域名分组、按过期时间、按剩余额度、按昵称排序。
  • 一键切号：写入前自动备份 secret-storage.xml；支持回滚上一次切换、强制登出当前账号。
  • 待生效补偿：IDE 退出时若用旧凭据覆盖，下次启动自动补写并提示重启。
  • 额度监控：可配置自动刷新间隔区间（最小 ~ 最大分钟，后台每轮随机取值）、低额度提醒阈值，低额度时弹窗提醒且每账号每周期只提醒一次。
  • 额度明细：总剩余 / 总量与百分比、套餐分组折叠展开、细项已用量与到期时间、多账号汇总视图。
  • 智能调度：优先消耗即将过期的额度，其次选择剩余最多的账号；可设置低额度阈值自动切换。
  • 状态栏组件：显示当前账号与额度，支持总剩余百分比、剩余总量、各套餐摘要、最紧张套餐、指定套餐五种维度；悬停看明细，点击打开面板。
  • 历史对话浏览：跨账号扫描、关键字搜索、账号过滤、时间分组，支持复制、导出 Markdown、打开会话目录；目录扫描（含子目录、可停止、跳过与错误明细）整合在同一窗口。
  • 历史共享：把全部账号的会话索引合并到当前账号并复制缺失的消息目录，也可批量同步全部账号。
  • 账号库备份：导出为 JSON 并可重新导入。
  • 首页看板：今日消耗积分大号数字、关键指标、智能调度、账号额度排行、30 天到期看板与数据状态；卡片可点击跳转对应功能页。
  • 消耗明细：按账号与今天 / 近 7 天 / 近 30 天查看每次请求的时间、产品、模型、积分、使用端与提示词摘要，含合计积分、模型分布与分页。
  • 对话日报 / 周报：按项目 / 账号 / 日期 / 时段 / 会话类型统计，支持维度筛选、时间快捷按钮、会话搜索、复制 Markdown 与「用 CodeBuddy 生成」正文。
  • 今日签到 / 一键签到：对账号库中所有账号执行每日签到，按本地按日记录逐账号展示今日是否已签与本次签到结果。
  • 成长中心：逐账号展示任务完成数、待领奖与进行中进度；「一键完成」自动接取任务、上报客户端行为事件并领奖，独立窗口另提供旅行巡检、活跃上报、全部保活、连登兑换、抽奖与补签。
  • 模型积分限额：可同时监控多个模型，每条规则独立限额与预警阈值；模型从官方目录加载或手填关键字，达标时提醒切换账号，剩余低于阈值时预警。

使用方式

  1. 打开 Tools | CodeBuddy Account Manager，或点击状态栏的 CodeBuddy 组件。
  2. 点击 从 auth 目录导入，把本机已有账号加入账号库。
  3. 选中账号后点击 切换，按提示重启 IDE 生效。
  4. 点击 刷新额度 或 额度明细 查看用量；在 Settings | Tools | CodeBuddy 账号管理器 中开启自动刷新、低额度提醒与自动调度。

环境要求

  • Windows 系统（依赖本机 CodeBuddy 数据目录与 JetBrains 配置目录）。
  • IntelliJ IDEA 2026.2（build 262）。
  • 已安装 CodeBuddy 插件（com.tencent.cloud.codingcopilot）并至少登录过一个账号。

数据与隐私

  • 账号快照保存在 IDE 配置目录的 codebuddy-accounts/ 下，修改 secret-storage.xml 前生成带时间戳的 .bak 备份。
  • 额度查询仅在本机与 CodeBuddy 服务端之间进行，插件不上传、不代理账号数据；签到与成长中心请求也只与官方服务端通信。
  • 导出的 JSON / Markdown 由用户自行保管，导出文件包含完整凭据。

已知限制

  • 常规切号需要重启 IDE，CodeBuddy 插件启动时才重新读取凭据。
  • 热切换为实验特性，依赖 CodeBuddy 插件内部实现，版本不同时自动降级为重启生效。
  • 同一 UID 在不同域名下属于不同账号。
  • 历史同步只处理目标账号已存在的工作区目录，只新增不覆盖。
  • 今日签到与成长中心接口非官方公开接口，路径与字段可能随版本变化，失败只提示且可在设置页改路径或关闭。
  • 模型限额只做统计与预警，不会拦截 CodeBuddy 客户端的模型调用。
