刻意没动的地方

克制也是交付的一部分。以下几处看着像可优化，实际动了会付出更大代价。

发布片段不加站点样式docs/ 两份 HTML 与 plugin.xml 的 <description> / <change-notes> 仍是纯 HTML 片段。套完整站点样式会破坏发布链路，只补了内容。
描述首句保持英文release.md 记过一次 400 错误：description must start with Latin characters。中文开头会被 Marketplace 拒，不能为了统一排版改掉。
黄铜读数不改色#9B7826 的 3.89:1 对大字合规；改它会同时破坏三份 HTML 与 cabinet-swing-preview.html 里 HTML 变量 → Kotlin 字段的一一对应。
不动组件结构与业务逻辑Swing 侧只改了一个颜色常量，其余全部进清单。改结构需要重新编译并做实机走查，属于另一个工作量级。
不拿设计预览冒充截图本机无法截取 IDE 实机画面，所以没有替换真实截图，只在描述页如实标注版本差异。CHANGELOG 缺 0.12–0.21 的记录，本次也只归并既有事实，没有虚构中间版本。
