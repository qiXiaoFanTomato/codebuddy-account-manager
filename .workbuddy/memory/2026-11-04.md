## 前端设计提案：CodeBuddy Account Manager 产品主页
- 交付：`design/index.html`（单文件 HTML，内嵌 CSS/JS，可直接预览）。
- 项目本质：JetBrains IDE 插件，本机多账号凭据快照归档、切号/回滚、额度台账、跨账号历史会话合并；全程本地、非官方组件。README / CHANGELOG / `src/main/kotlin/.../ui/AccountUiColors.kt` 是主要信息源。
- 视觉主张「档案柜 / The Cabinet」：从「凭据档案卡抽屉」隐喻长出版式，刻意**不沿用**插件内已有的墨青 UI（AccountUiColors.kt 自述「素墨仪表」），只保留其等宽仪表数字与香槟金积分语义作呼应。
- 配色：档案纸 `#E8ECEF` / 卡面 `#F7F9F9` / 墨蓝 `#1B2A3A` / 朱印 `#B23A2C`（唯一高饱和，只给「当前激活」与临期警示）/ 黄铜 `#9B7826`（积分读数、进度条）/ 铅线 `#C6D0D7`。
- 字体：IBM Plex 家族（Sans Condensed 标题与 tab、Sans 正文、Mono 只给数字/路径/状态栏/日志）+ 中文系统回退。
- 版式：hero 档案卡（凸起 tab、微旋朱红印章、带刻度的黄铜进度条、虚线撕口与文件号）、放大的 IDE 状态栏读数带、错位半抽出的索引卡、账本式额度表格、朱红左粗边的隐私声明、签署栏式页脚。
- 交互：点「切换」→ 卡面与状态栏读数更新并追加 `secret-storage.xml` 备份日志；点「回滚」恢复。按钮与提示文案一致（切换 → 已切换 / 回滚 → 已回滚）。
- 基线：响应式断点 900/600、`focus-visible`、`prefers-reduced-motion`、语义标签；不用全大写 eyebrow、装饰性 01/02/03、`→` 与渐变 hero；CSS 用 `.band { padding-block: var(--band-y) }` + 修饰符改变量，避免区块类互相抵消 padding。
- 自审：bash 运行时缺 coreutils 导致浏览器截图链路不可用，改用 Python `html.parser` 做静态校验（ID 引用、CSS 变量、标签闭合、UTF-8 编码全部通过）。
